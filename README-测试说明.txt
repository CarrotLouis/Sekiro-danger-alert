Sekiro danger alert 0.6.0 — 16 招自动预警版

本版用途
Crusher / 普通重炮塔保持原预警；采集的 16 个新增招式已接入。
只有本机拥有的敌人 AI 有效锁定本人，并进入对应招式窗口时提示，不限距离。
主设置页 13 项，Sekiro danger alert - Attacks 页 30 个独立开关，默认开启。
本版经过离线回放和封包检查，新增预警时机仍需游戏内实测。

安装
在 HD2Arsenal 用本包替换旧版，同 GUID 只启用一个版本，部署后完整重启。
依赖 Bingus Shared Loader v18+、ModOptionsMenu v1.2 / API 3。
只适配 Steam build 25480438；进入舰船后等待约 30 秒。
不需要在游戏中安装 HD2Runtime。

新增招式
四种强袭虫跺脚；穿刺虫跺脚和触手下砸；吐酸泰坦戳腿和吐酸；
蟑龙俯冲吐息；孢裂泰坦戳腿；巨型者和巨型炙焰者劈砍；
移动工厂炮击；强化纵步者火箭；湮灭坦克炮击；铁幕坦克直射火箭。
蟑龙悬浮吐息不触发，铁幕坦克向上抛射不触发。
铁幕坦克直射一轮三发，各发有独立预警窗口，由同一个招式开关控制。
提前预警不能预测后续取消；移动工厂在开火准备后未开炮时也可能已提示。

设置
位置、大小、音量、自动预警、试听和动画预览仍在主页面。
各招式开关分别控制，例如吐酸泰坦戳腿 / 吐酸、穿刺虫本体 / 触手互不影响。
蟑龙设置改名为俯冲吐息，保留原保存 ID 和开关值。
Crusher 按 13 个原生近战分支独立控制，跺脚继续排除。
恢复全部默认值：选择恢复并 APPLY，跨页恢复全部选项，所有招式开启，
音量 60、偏移 0、大小 100%、自动预警开启，停止采集并取消预览队列。
不会播放声音、启动采集或修改其他模组设置。

漏报采集
1. 主页面选择“新招式采集目标”。
2. “采集类型”选择目标招式，开始两分钟采集并 APPLY，关闭菜单。
3. 看到指定招式准备时按 F8。每轮一次；晚按可以回溯。
   F8 只标记、不手动显示危。尽量录视频并获得 3～5 轮。
4. 换招式前先停止，再选择并开始；重复开始会关闭旧文件并另建新文件。
5. 铁幕坦克抛射、蟑龙悬浮等反例用“对照动作”记录。
6. 自动预警决策同时记录，反馈时说明该次是否看到危，以及误按序号。

日志目录
%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs
Sekiro danger alert.log：版本、状态、automatic_trigger 及读取错误。
Sekiro danger alert-Combat-招式ID-requested/comparison-日期-时间.jsonl：研究采集。
用户选择的 requested_move 只是采集标签，不表示程序识别了那次攻击。
原始 Crusher / Targeting 采集仍保留。

边界
自动读取每批 2500 次 / 1 MiB，攻击表和工厂描述符分批续扫；没有固定敌人观察名额。
手动采集最多两分钟、8 MiB、8 个相关候选；2000 米范围仅用于诊断选择。
默认约 20 Hz，耗时较大降频；超 20 ms 或累计八次读取失败停止采集。
8 MiB 截止前的数据有效，之后需要另开一份继续。
只信任本机拥有的有效 AI 实体目标；客机同步尚未验证。
攻击被取消、转向、遮挡或受伤中断时，已经发出的危提示可能保留到结束。
未见过的动作变体或游戏更新后的时序需要继续验证。

离线与实机
离线验证 16 个自动路径、真实设置框架、各项开关 / 全部恢复、原生读取边界，
并回放 6,169 条匿名采集状态；抛射与悬浮吐息为实际采集反例。
移动工厂另核对原生 AI 准备、就绪标志、微秒时钟与实体扫描，合成内存中验证。
这些不是新增版本的游戏内确认。请先单人测试各招式与飞扑窗口。
详细证据：源码仓库 docs/VALIDATION-0.6.0.md。

生成测试敌人
可搭配独立工具 Sekiro danger alert - Enemy Spawner 0.1.1，需另装。
仅对应阵营的单人主持任务；穿刺虫请在 5 难以上生成。
两者 GUID、设置页和日志独立。

素材和音频
沿用已确认 R2：50 帧 512×512 原生游戏纹理 / 材质，持续约 0.834 秒。
每帧追随本机潜兵头部，保留左右 / 上下偏移和 50%～300% 大小调整。
不使用游戏外浮窗，不含字体原文件，不需要 AE 工程。
音效使用本模组独立的 WinMM PCM 通道和音量；不受游戏音效滑块控制，不是 Wwise 事件。

卸载
在模组管理器禁用本包、部署并重启。日志保留。
