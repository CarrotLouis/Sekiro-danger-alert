Sekiro danger alert 0.5.0 — 逐招式设置 / 新招式采集版

本版用途
上一版已获用户单人测试确认。Crusher / 普通重炮塔继续预警。
新增 16 个待确认招式的默认开启开关，以及逐招式、可带对照标签的采集。
这些新招式尚未绑定前摇事件，本版不会自动提示；采集后再逐项接入。
主设置页 13 项，Sekiro danger alert - Attacks 页 30 个招式开关。

安装
在 HD2Arsenal 用本包替换旧版，同 GUID 只启用一个版本，部署后完整重启。
依赖 Bingus Shared Loader v18+、ModOptionsMenu v1.2 / API 3。
只适配 Steam build 25480438；进入舰船后等待约 30 秒。

设置
原有位置、大小、音量、自动预警、试听和预览仍在主页面。
新招式开关分别控制每一个招式，吐酸泰坦戳腿 / 吐酸等独立。
Crusher 暂按 13 个已识别的原生能力分支编号独立控制，跺脚继续排除。
恢复全部默认值：选恢复并 APPLY，跨页恢复全部选项，所有招式开启，
音量 60、偏移 0、大小 100%、自动预警开启，停止采集并取消待执行预览。
恢复操作不会播放声音或启动采集，不修改其他模组设置。

新招式采集
1. 在任务内打开主设置页，选择“新招式采集目标”。
   包含四种强袭虫跺脚、穿刺虫本体 / 触手、吐酸泰坦戳腿 / 吐酸、
   蟑龙吐息、孢子泰坦戳腿、巨型者劈砍、移动工厂炮击、强化纵步者火箭、
   湮灭坦克炮击、铁幕坦克直射火箭、巨型炙焰者劈砍，共 16 招。
2. “采集类型”选目标招式，开始两分钟采集并 APPLY，关闭菜单。
3. 看到指定招式起手后 F8，一招按一次，获得 3～5 次即可。
   允许晚按；F8 只标记、不手动显示危字。最好同时录视频。
4. 换招式时先停止，再选新目标开始，每份独立记录。
   吐酸泰坦戳腿 / 吐酸分别采；穿刺虫本体 / 触手分别采。
5. 铁幕坦克需要两份：目标招式模式记录直射，对照动作模式记录向上抛射。
   其他敌人也可用对照类型记录冲锋等易混淆动作。
6. 可以分批给数据，先普通强袭虫或吐酸泰坦即可，不必一次找齐。
   单人 / 本人房主优先，尽量减少同类敌人混杂。新旧三种采集互斥。

日志目录
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs
Sekiro danger alert-Combat-招式ID-requested/comparison-日期-时间.jsonl
旧 Crusher / Targeting 日志与主日志仍保留。
记录本体及相关炮塔子实体、AI 目标 / 阶段、未知能力及计时、武器输入、
动画变化、F8 最近观察和样本年龄。用户选择的 requested_move 不代表已识别攻击。

边界
新采集最多两分钟、8 MiB、8 个相关候选；范围 2000 米只用于采集选择。
默认 20 Hz，耗时较大时降频；单次超 20 ms 或累计八次读取失败停止。
完整 AI 状态增大日志，敌人多时可能先达到 8 MiB，重新开始一份即可。
健康组件可发现没有 Ability 组件的坦克炮塔；只有瞄准或武器输入不代表前摇确认。
巨兽 / 巨型炙焰者 / 强化纵步者等变体仍需实测身份，不把候选类名当作精确匹配。
既有自动预警仍只信任本机拥有的有效 AI 目标；客机同步未验证。

离线与实机
离线测试覆盖真实设置框架、独立开关、恢复默认值、未知动作采集、
只读布局与所有者校验、分析和旧警报回放。新采集路径及 16 个招式仍待实机。
详细资源和取证说明见源码仓库 docs/ENEMY-EXPANSION-0.5.0.md。

素材和音频
采用 50 帧 512×512 游戏纹理/材质和原生 GUI，不使用游戏外浮窗。
动画约 0.8 秒，来自字体字形、动态杂色、红色着色与多尺度辉光，按参考图独立近似实现。
没有调用 AE 插件，字体原文件不包含在封包或公开仓库中。
声音通过本模组独立的 WinMM PCM 通道播放，不受游戏音效音量滑块控制，也不是 Wwise 事件。
不需要 AE 工程，不需要安装 HD2Runtime。

卸载
在模组管理器禁用本包、部署并重启游戏。日志会保留。
