# Sekiro danger alert 1.0.0

[English](https://github.com/CarrotLouis/Sekiro-danger-alert/blob/main/README.md) / 简体中文

这是一个《绝地潜兵 2》Lua 模组：当敌人针对本人准备已识别的危险招式时，在潜兵头顶显示只狼风格的“危”图标并播放警告音。

## 安装

在模组管理器中导入 Sekiro danger alert 1.0.0.zip，替换旧版本、部署并重启游戏。同一模组只启用一个版本。游戏启动后约 20 秒开始工作。
依赖 Bingus Shared Loader v18+ 和 Mod Options Menu v1.2（API 3），无需安装 HD2Runtime。适配 Steam build 25480438。

## 设置

全部 29 项设置集中在一页。标签、说明及自定义选项文字跟随游戏的文本语言：英语、法语、意大利语、德语、西班牙语、西班牙语（拉丁美洲）、日语、韩语、波兰语、葡萄牙语、葡萄牙语（巴西）、俄语、简体中文和繁体中文。
修改后按游戏的应用按钮保存。升级保留已有设置标识及其保存值。

20 个招式开关全部默认开启，按阵营排列：

- 终结族：强袭虫、孢子强袭虫跺脚；巨兽级强袭虫跺脚；爆裂强袭虫跺脚；穿刺虫跺脚与触手下砸；吐酸泰坦戳腿与吐酸；蟑龙俯冲吐息；孢裂泰坦戳腿。
- 机器人：加农炮台炮击准备；巨型炙炎者及喷气旅巨型炙炎者劈砍；移动工厂炮击；强化侦察纵步者火箭弹；湮灭坦克炮击；铁幕坦克直射火箭。
- 光能者：粉碎者锤击；猎杀器电击与激光。

粉碎者各类锤击共用一个开关。蟑龙仅对俯冲吐息预警，铁幕坦克仅对直射火箭预警。粉碎者跺脚、蟑龙悬浮吐息及铁幕坦克抛射不预警。
左右和上下位置以默认头顶锚点为 0，左右范围约各一个身位，上下约各两个头高。图标跟随头部和镜头移动，包括蹲下与卧倒。攻击识别没有敌人距离限制。
大小范围为 50%～300%，默认 100%。音量范围为 0～100，默认 60；0 为静音。
猎杀器电击与激光各有独立的 0～0.5 秒延迟，步进为 0.01 秒，默认 0.30 秒。已有保存值会在新范围内保留，恢复默认值可应用新默认值。取消攻击、切换目标、死亡或失去有效攻击状态会取消待发提示。延迟过长可能使预警晚于伤害。
立即试听：选择播放一次并应用，即可按已保存的音量播放。动画预览：应用后关闭菜单，三秒后播放图标和音效。
恢复全部默认值会开启所有招式，将位置归零、猎杀器两项延迟恢复为 0.30 秒、大小恢复为 100%、音量恢复为 60，并取消待执行的预警和预览。

## 运行文件

默认目录：%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\
通常展开为：C:\Users\<your username>\AppData\Local\CowboyBingus\Helldivers2\Logs\
如果加载器指定了自定义日志目录，以下文件使用该目录。

本模组直接产生：

- Sekiro danger alert.log：以追加方式记录启动、就绪状态及错误。

设置由 Mod Options Menu 保存，与其他模组共用：

- ModOptionsMenu.values：已保存的设置；本模组使用 peril_warning.crusher. 前缀。
- ModOptionsMenu.values.bak：上一份设置备份。
- ModOptionsMenu.values.tmp：保存时产生的临时文件，成功后改名为正式设置文件。

ModOptionsMenu.log 和 BingusSharedLoader.log 由对应依赖各自管理，不由本模组直接写入。
动画与声音内置于封包，运行时不导出 PNG、WAV 或本模组单独的配置文件。
导入与部署产生的副本由模组管理器管理，位置取决于所用管理器。

## 性能与使用范围

攻击判定每秒最多运行 20 次。头部投影仅在约 0.83 秒的动画播放期间更新，没有常驻可见叠加层。文字跟随设置界面刷新，不增加逐帧语言读取。日志不逐次记录攻击。
50 张压缩动画纹理的资源数据约为 8.34 MiB。声音使用约 0.92 MiB 的内置 PCM，并从内存播放。这些数字是资源载荷大小，不是游戏总内存占用。实际开销取决于场景和设备，不提供固定帧率影响的承诺。
预警不等于命中预测，也不保证飞扑能躲开伤害。敌人可能在提示后取消攻击或更换目标。
移动工厂准备后取消攻击可能仍有提示；联机客机的蟑龙提示可能不准确。
游戏布局不受支持时会停止自动预警，详情见 Sekiro danger alert.log。

## 卸载

在管理器中禁用本模组，部署并重启游戏。可手动删除 Sekiro danger alert.log。
ModOptionsMenu.values 及其备份与其他模组共用，不要为了清除本模组设置而删除整个文件。
