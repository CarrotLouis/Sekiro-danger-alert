Sekiro danger alert 0.7.0

安装
在模组管理器导入本 ZIP，替换旧版本并部署，完整重启游戏。
同一 GUID 只启用一个版本。
依赖 Bingus Shared Loader v18+、Mod Options Menu v1.2 / API 3。
只适配 Steam build 25480438；进入舰船后等待约 30 秒。
无需另外安装 HD2Runtime。

效果
敌人有效锁定本人、进入已识别招式的预警窗口时，在潜兵头顶显示“危”并播放音效。
图标始终跟随本机潜兵；不按敌人与潜兵之间的距离判断。
沿用已确认的动画和招式映射；本版增加客机同步目标和移动工厂同步准备信号读取。
客机修正已通过离线检查，真实联机及飞扑窗口仍需实测。

设置
所有 25 项集中在 Mod Options Menu 的 Sekiro danger alert 一页中。

18 个招式开关，默认全部开启：
1. 粉碎者 · 危险近战：统一控制所有已识别变体，继续排除跺脚。
2. 普通重炮塔开火准备。
3. 强袭虫跺脚。
4. 孢子强袭虫跺脚。
5. 巨兽强袭虫跺脚。
6. 钻地强袭虫跺脚。
7. 穿刺虫跺脚。
8. 穿刺虫触手下砸。
9. 吐酸泰坦戳腿。
10. 吐酸泰坦吐酸。
11. 蟑龙俯冲吐息：不预警悬浮吐息。
12. 孢裂泰坦戳腿。
13. 巨型者劈砍。
14. 移动工厂炮击。
15. 强化纵步者火箭弹。
16. 湮灭坦克炮击。
17. 铁幕坦克直射火箭：不预警抛射，直射三发分别提示。
18. 巨型炙焰者劈砍。

其余 7 项：左右位置、上下位置、大小、音量、立即试听、动画预览、恢复全部默认值。
位置以既有头顶锚点为 0，大小范围 50%～300%，音量范围 0～100。
选择试听或预览后按 APPLY；动画预览在三秒后播放，请关闭菜单查看。
恢复默认值并 APPLY：所有招式开启、位置归零、大小 100%、音量 60，并取消待执行预览。

升级
GUID、内部资源路径及保留选项的保存 ID 不变，位置、大小、音量及其他敌人开关继续保留。
“粉碎者 · 危险近战”仅更改显示名称，沿用上一包的合并开关 ID 和保存值。
旧分支开关及采集选项不再读取；旧版总开关也不再控制本版。
若要关闭全部预警，请关闭各招式开关，或在模组管理器禁用本模组。

安装包内容
不含采集、F8 标记、索敌诊断、敌人生成工具或逐次攻击事件转储。
记录基本启动、设置、错误及每 30 秒最多一行的观察统计至：
%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/Sekiro danger alert.log

注意
房主使用本机有效 AI 目标；客机核对同步网络目标、已处理的目标 ID 和本次潜兵身份。
客机常规招式还要求攻击计时正在推进；目标数据缺失或计时停滞时不猜测。
移动工厂客机路径观察新一轮准备信号；加入房间时已经亮灯、扫描中断或后续转向本人不补发旧预警。
提前预警无法预测攻击之后是否取消；移动工厂准备后不发射时，也可能已经提示危。
游戏更新后需重新核对版本。建议客机先复测巨型者劈砍、移动工厂炮击，并对照它们攻击队友时是否保持安静。
音效使用独立 WinMM PCM 通道，音量仅由本模组的设置控制。

卸载
在模组管理器禁用并部署，完整重启游戏。
