Sekiro danger alert 0.8.3

安装
在模组管理器导入本 ZIP，替换旧版本并部署，完整重启游戏。
同一 GUID 只启用一个版本。普通包和 Diagnostics 采集版互相替换，不要同时部署。
依赖 Bingus Shared Loader v18+、Mod Options Menu v1.2 / API 3。
只适配 Steam build 25480438；启动后等待至少 20 秒。无需安装 HD2Runtime。

效果
敌人锁定本人、进入已识别招式的预警窗口时，在本机潜兵头顶显示“危”并播放音效。
图标始终跟随本机潜兵；不按敌人与潜兵之间的距离判断。
客机核对同步目标和攻击计时；移动工厂客机路径使用新一轮同步准备信号。
保留 0.8.2 的客机共用索敌表修复；用户报告房主和客机已基本可用。
本次主要扩展可选 Diagnostics，预警规则与时机没有变化，不是蟑龙 / 移动工厂误报修复包。
已确认蟑龙俯冲时 AI 与旧瞄准目标可能不同；移动工厂闪灯可能结束而不开炮。
尚未核实移动工厂“确认会开炮但尚未发射”的可靠中间态，没有改为开炮后报警。
猎杀器两招沿用已核对的单人映射和独立延迟，不改默认值与时机。

设置
普通包共 29 项，集中在 Sekiro danger alert 一页。20 个招式开关全部默认开启。
按虫族、机器人、光能族分组，组间留空；同一个敌人的两个招式分别控制。
虫族：四种强袭虫跺脚、穿刺虫跺脚及触手下砸、吐酸泰坦戳腿及吐酸、蟑龙俯冲吐息、孢裂泰坦戳腿。
机器人：普通重炮塔、巨型者劈砍、移动工厂炮击、强化纵步者火箭、湮灭坦克炮击、铁幕坦克直射火箭、巨型炙焰者劈砍。
光能族在招式列表最下面：粉碎者 · 危险近战、猎杀器 · 电击、猎杀器 · 激光。
继续排除粉碎者跺脚、蟑龙悬浮吐息、铁幕坦克抛射；铁幕坦克直射三发分别提示。

猎杀器两个招式开关后分别有延迟滑块：0～2 秒，步进 0.1 秒，默认 0。
0 保持原时机；APPLY 后对下一次攻击生效，图标和音效一起延后。
攻击结束、切招、转向队友、死亡、增援或观察中断会取消待发提示。
延迟过长可能晚于伤害；上限是测试范围，不会自动修正为最佳飞扑值。

其余 7 项：左右位置、上下位置、大小、音量、立即试听、动画预览、恢复全部默认值。
位置以既有头顶锚点为 0，大小范围 50%～300%，音量范围 0～100。
选择试听或预览后按 APPLY；动画预览在三秒后播放，请关闭菜单查看。
恢复默认值并 APPLY：所有招式开启、位置归零、大小 100%、音量 60、两种延迟 0，并取消待执行预警和预览。
GUID、入口及原有保存 ID 不变；调整设置顺序不会重置旧开关和外观值。

采集版
Diagnostics ZIP 包含完整本体，并额外增加一个采集设置页。普通 ZIP 没有采集和 F8 功能。
客机问题必须由客机在自己的电脑采集本人被攻击；主机采集朋友被打不能替代。
按阵营选择招式，开始并 APPLY，看见出招按 F8，结束后停止并 APPLY；两分钟自动停止。
开始后先在说明区确认“正在采集”、有效样本数增长；F8 标记后次数也应增长。
停止时显示实际原因及有效样本数，不把读取尝试次数当作有效数据。
只需先选一个敌人验证共用链路，不要求重新寻找全部敌人。
若使用生成工具，房主和客机都更新到 0.3.1，覆盖部署后完整重启。
详细分工和步骤见采集版内 README-采集说明.txt。

日志与限制
%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/Sekiro danger alert.log
普通包不保存逐次攻击转储；每 30 秒最多一行观察统计。
目标数据缺失、位置目标、攻击别人、旧潜兵、计时停滞或错过窗口时不猜测。
提前提示无法预知之后是否取消攻击；移动工厂亮灯后不开炮也可能已经提示。
猎杀器只按当前锁定目标判断，不能预测激光后续扫射或电击连锁波及其他潜兵。
游戏更新后需重新核对版本。音效仅由本模组音量设置控制。

卸载
在模组管理器禁用并部署，完整重启游戏。
