# Changelog

## 1.0.0 — 2026-10-16

- Added complete single-language settings for all game text languages, including separate regional Spanish, Portuguese and Chinese translations.
- Kept the established attack windows, approved animation, head tracking, 20 attack switches, Harvester delays and existing saved setting identifiers.
- Harvester electric shock and beam delays range from 0 to 0.5 seconds in 0.01-second steps, defaulting to 0.30 seconds each.
- Reduced factory discovery CPU work, cached verified head-node lookup and removed routine per-alert disk logging.
- Documented runtime files and their locations, including shared settings backups and temporary files.
- Bundled English and Chinese user guides and the dependency licenses.

Factory Strider preparation cancellation and co-op guest Dragonroach targeting remain known limitations.
