## 数据可用性与标注

本机日志覆盖全部 16 项。23 份 Combat 文件均可解析，有 start / stop，没有 read_error；人工 F8 是延迟标记，不能当成精确起手时间。原始日志、完整 AI 状态、静态模块截取和 FileDiver 原表不入库。自动规则根据原生资源、能力时钟 / 阶段和当前本人实体目标，**没有用 F8 时刻作为运行时延迟常量**。

补测的两个完整抛射周期各约 6.85 个能力时钟秒，6 个 F8 全在能力 1019 内。此前三轮近距离直射为 1018。补测文件名 / header 仍是 requested，但用户明确说明这次只标抛射，因此按人工确认的对照处理。该份开头另有未标记的 1018 直射周期，不能把整份文件的所有动作都当作抛射。

移动工厂第 3 次 F8 的准备周期未见发射输入，保留为取消 / 未开炮例；第 2 次接近前一轮结束，不另算一轮。湮灭坦克第 9 次 F8、巨兽强袭虫第 5 次 F8 按用户说明排除为目标动作确认。重启采集仅先结束旧文件、再开新文件，原记录可用。8 MiB 截止不损坏截止前的数据。

## 原生证据与移动工厂

保持 Steam build 25480438，game.dll SHA-256 `2E2C3B7C2500646DADD5F2B4C6E0504DBB7E7896139F64CDDC0D1813C718F51E`，exe SHA-256 `F5FEE03DCFDB2E553A4752C283590950AC13316B376D8196AA556FF0400D5F06`。常规索敌、活动 / 暂停位和 60 ticks/s 校验沿用原版；新增 78 处代码片段与本机保留代码逐项匹配，涵盖 24 个能力分派 / 处理路径与工厂字段。

工厂炮台没有活动 Ability，不能把本体生成 / 移动的 1014 当作炮击。独立核对：

- 世界描述符 `world+0xF32F18`，2048 条 × 24 字节；空实体 global `game+0x348456C`。扫描精确炮台资源，复核 canonical 指针与健康身份，不读位置、不用距离。
- 工厂状态入口 `0x1C4A90`。其上下文中的 AI 子结构基址是完整 Behavior 记录 +8；进入准备阶段 3 写 full record +`0x188` 的微秒时间。不能把子结构偏移直接当完整记录偏移。
- `0x1C3A7D..0x1C3ACF` 设置子结构 +`0x1E0` 的 bit 28（full record +`0x1E8`）并开启目标准备灯；因此单独阶段 3 或闪灯不足以证明已经发射。
- `0x1C3ACF..0x1C3B1F` 用 `[ptr(game+0x3326348)+0x18]` 的原生微秒时间检查准备至少 1,000,000 μs，且按 500,000 μs 节奏进行开火评分。
- `0x1C4294..0x1C42C6` 评分成功才提交武器输入和效果。准备后可能因目标、遮挡、评分等因素取消；本版提前窗口不等待发射发生。

工厂扫描每批最多 8 个匹配，达到后续扫，不把该值当永久观察名额；普通活动表继续每批 2048 行 / 32 个匹配后续扫。两条路径合用 2500 次 / 1 MiB 的读取上限。全程只读，没有新的原生函数调用、注入或游戏内存写入。

**限制：工厂准备的实际开炮时间会变化，且可能始终不发射。提前提示不能预知这一结果，取消后也可能已经显示危。** 实际飞扑窗口必须复测。

## 已完成的离线检查

- 实际游戏 `lua51.dll` 编译封包，所有函数低于 LuaJIT 字节码限制；真实 ModOptionsMenu v1.2 / API 3 注册 13 个主设置 / 30 个开关，独立开关、默认值恢复和保存 ID 通过。
- 原有内存辅助层的 16 个私有 FFI 别名在游戏 LuaJIT 的独立测试进程中全部解析成功，计时与模块 SHA-256 调用通过。通用正则扫描器不识别该层的变量 `cdef` / `__asm__` 别名，静态缺声明报告已逐项核对；本次没有增加 FFI 声明或调用。
- 6,169 条来自 18 份实际采集的匿名、约 10 Hz 稀疏状态回放，保留能力时钟 / speed / 生命周期 / 本人目标，不包含原始身份、地址、完整 AI / 武器状态或 F8。15 个 Ability 路径均产生对应事件；直射三轮得到 9 个分段事件；所有 1019 与 252 样本为零预警。补测文件开头的真实 1018 仍产生 3 次直射提示。
- 回放中未标记的攻击仍可提示，且准备后取消的攻击仍可能提示；回放事件数不等于 F8 数或确认的命中次数。湮灭坦克误按对应的准备本身仍可能满足预警条件，不能声称已预知“只亮灯”。
- 工厂生产读取器在合成内存中检查 full record 字段、实际微秒差、就绪位、canonical 健康 / AI / 世界描述符、invalid / 销毁标志、25 个炮台的轮转和指令不符拒绝。另测试 16 个事件路径、按招式关闭、多个发射窗口去重、别人 / 无目标 / 死亡 / 替换 / 模式排除和场景更替。
- 原 Crusher、普通重炮塔真实回放以及已确认 R2 素材、头顶跟随 / 偏移 / 缩放 / 音量检查继续通过。

工厂实际采集没有直接保存当前原生全局时钟，本轮**没有声称已精确回放其真实提示时刻**；原生偏移 / 计时语义由代码确认，读取与决策由合成边界验证，真实数据提供阶段 / 就绪 / 发射与取消上下文。
