# Sekiro danger alert — 动画预览 R1（待确认）

历史记录：当前预览工具已更新为 [R2](ANIMATION-PREVIEW-R2.md)，下述内容记录 R1 当时的方案与输出。

本次仅修改动画预览。按用户要求，确认观感前不替换 `assets/frames`、不修改游戏材质、不构建新的游戏包。当前游戏版本仍为 0.3.0。

逐帧查看用户提供的原视频：大型半透明字在前几帧迅速展开，第 24 帧已退场；主体仍在淡出，第 49 帧为空白。这里使用从 0 开始的帧号。

R1 的独立实现使用用户提供的「極太行書」字体：

- 主体从 0.74 倍缓慢放大到 1 倍，在第 14 帧达到亮度峰值，然后立即淡出；淡出时几何尺寸与纹理亮纹均固定。
- 第二层使用独立字形、缩放与透明度曲线，快速放大至主体的 1.92 倍，在第 24 帧完全消失。
- 亮部改为浅珊瑚粉与粉白，保留流动明暗纹理；柔化字缘，大字层更加柔和。
- 光晕使用浮点多尺度高斯卷积与两倍分辨率渲染，再对预乘颜色缩小、编码透明 PNG，避免从视频低分辨率光晕放大而产生断块。
- 共 50 帧，60000/1001 fps，时长约 0.834 秒；第 49 帧完全透明。

这是程序化重建，不是 AE 插件输出或原作像素级复刻。768² 预览用于检查动画细节，尚未验证游戏材质压缩后的效果与屏幕大小。
