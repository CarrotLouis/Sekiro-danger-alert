# Sekiro danger alert 0.3.0：攻击研究与验证范围

## 字体动画

用户提供的字体内部名称为 `HakusyuGyosyoExtraBold`。程序直接渲染“危”字形，生成四层动态杂色、纵向拉伸纹理、红色着色、多尺度辉光和放大淡出。截图中的对比度 150、复杂度 4、纵向 223%、演化 -120° 和辉光曝光 1.5 用作重建参考。

这是独立的程序化近似；截图没有完整动画曲线及插件工程，不能复刻 AE / VC Color Vibrance / Deep Glow 的逐像素输出。字体从用户路径读取，原文件不复制、不上传。48 张 512² R/G 遮罩已包含在源码中，构建不依赖外部字体；`assets/effect.json` 保存参数与字体摘要。

与旧版大量透明留白的 256² 视频帧相比，新版字形在 512² 贴图中约高 300 像素，显示时缩小画布，使默认字形大小接近旧版。不同字形和光晕包围盒不可能完全相同。

## 调整方式

- 左右 / 上下：-100 至 100，默认 0。0 保留旧版头顶投影锚点；正数向右 / 向上。
- 两个方向的最大偏移均为画面高度的 10%：1080p 下是左右、上下各 108 像素。大致对应一个身位、两个头高；人物的屏幕尺寸随 FOV、姿态及镜头距离改变，因此不是精确骨骼尺寸。
- 大小：50%～300%，默认 100%，步长 5%。围绕锚点缩放；放大不会额外扩大偏移上限。
- 每帧重新计算头部投影。无法读取头部或头部离开画面时继续隐藏，不回退到固定屏幕位置。

## Crusher 攻击范围

公开的 [Crusher Wiki](https://helldivers.wiki.gg/wiki/Crusher) 描述了挥棒前冲和较长攻击距离，但没有提供可直接用于本模组的完整招式编号表。网络攻略也不能建立“动作名称 → 运行时能力编号”的可靠映射。

本轮主要依据同一 Steam build 25480438 的留存运行时代码：通过能力分发表定位处理函数，再用 PE 异常表确定函数边界，核对各分支的前摇、成对判定启停与脚部节点引用。节点名称由 [FileDiver 字典](https://github.com/xypwn/filediver/blob/6bf7c1ccc4be465a35b4bc9d41087781b47034e6/hashes/thinhashes.txt) 的哈希复算辅助识别；字典和原始游戏数据均未打包。

| 能力编号 | 本版处理 | 证据及限制 |
| --- | --- | --- |
| 1411 / 1412 | 预警 | 原有采集与使用者实测支持普通下砸；保留原逻辑 |
| 1413～1417 | 新增预警 | 武器相关近战 / 多段判定路径；1415 有多组连续判定开启和恢复逻辑。具体动作俗名仍待实测 |
| 1418～1422 | 新增预警 | 其他近战判定分支；不能仅凭编号命名为某个具体招式 |
| 1424 | 新增预警 | 与下砸共享部分动画，但有独立判定启停路径；旧采集中出现过一次 |
| 1409 / 1410 / 1423 | 显式排除 | 脚部攻击分支，含 `l_ankle` 节点关联；即使误加到白名单，排除表仍优先 |
| 其余，包括 1434 | 不预警 | 没有足够证据作为攻击；10 米内的新动作起点会记录 `unmapped_action` 供后续核对 |

重要限制：上述新增覆盖来自静态研究，并不证明每个分支都能在当前战斗条件下出现，也不证明已经穷尽 Crusher 的全部攻击。用户描述的“三连锤击”应在实测中与触发日志对齐，当前没有把某个候选编号直接宣称为已确认的三连锤。

每个能力开始提示一次。同一连击能力内部的每个命中窗口不会重复播音；如果连击通过切换能力实现，则每个新攻击能力各提示一次。仍按起点距离 10 米限制，不计算目标朝向、伤害或命中轨迹。

## 验证

离线测试覆盖所有 13 个启用分支和三个排除分支、连续施放去重、范围边界、菜单滑块、移动中偏移和 0.5 / 3 倍缩放、字体纹理的透明边界与动画变化。旧采集 934 条能力记录回放仍得到 9 次范围内提示。1424 的一次起点距离约 15.55 米，正确受到 10 米限制而不触发；其范围内正例由独立模拟测试覆盖。

待游戏实测：新材质的实际颜色与清晰度、512² 纹理表现、滑块调整手感、三连锤对应编号及客机读取。程序只读游戏状态，继续受文件哈希与关键指令校验限制。

实测时若三连仍不提示，开启现有“Crusher 采集”，仅在三连开始时按 F8；无需精确同步，事后可从能力起点回溯。主日志中的 `automatic_trigger` / `unmapped_action` 可区分已触发、未映射与距离条件。
