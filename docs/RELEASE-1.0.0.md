# Sekiro danger alert 1.0.0

用户确认 0.6.0 单人实测无问题后，1.0.0 整理为发行包。攻击映射与时序、目标 / 所有权 / 健康身份判断、分批扫描上限和版本校验、R2 素材 / 头顶投影 / 音量接口不变。

## 单页设置

真实 ModOptionsMenu v1.2 / API 3 每分类最多 32 项。按用户要求将 Crusher 的 13 个原生分支视为同一招，合为一个开关后，共 25 项，可全部注册到 `peril_warning.crusher` 同一分类：

- 18 个默认开启的招式开关：合并的 Crusher、普通重炮塔和已有的 16 招。
- 4 个滑块：左右、上下、大小、音量。
- 2 个一次性预览：立即试听、三秒后动画加声音。
- 1 个全部恢复默认值：18 招开启、偏移 0、大小 100%、音量 60，取消待执行预览。

新 Crusher 开关 ID 为 `peril_warning.crusher.move.crusher_melee`，检测器仍识别原生变体，由菜单适配器把全部已确认分支路由到该开关；跺脚和未知分支仍不提示。旧 13 个分支设置按用户要求退休，不尝试把相互矛盾的旧值映射到新开关，新开关首次默认开启。

其他保留选项 ID、GUID `1dc82965-3c84-4eec-bb72-88e8121ac0dc`、入口 `mods/peril_warning/crusher_probe` 和公开名字不变。页面移动不改变 MOM 以选项 ID 保存的值。旧总开关和采集字段不注册、不读取；其残留保存数据不会阻止发行版预警，也不会启动任何操作。

## 从包中移除的内容

移除所有采集控制、F8 按键读取、JSONL 写入、索敌 / 武器输入 / 动画研究读法、按次 `automatic_trigger` 转储和 STATUS 文本。只保留启动、菜单拒绝、资源 / 读取失败和状态转换的基本日志。

研究源码移至 `tools/diagnostics/`，作为离线回归素材保留；生产 native reader 只有显式传入研究扩展时才会安装这些方法，发行入口从不传入，构建器也不包含扩展模块。构建只写入招式公开 ID / 标签 / 说明，不带采集选择和研究注释目录。敌人生成工具是独立工程，不在主模组 ZIP 内。

ZIP 仅含 manifest、使用说明、署名及原生 Lua / 材质 / 纹理档案。原始日志、游戏文件和第三方 checkout 不入库；维护者自行发布 Release。
