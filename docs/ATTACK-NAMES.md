## 多语言名称依据

- 敌人名称：安装游戏 Steam build 25480438 的各语言字符串资源。同一文字 ID 对应各语言原文，不从英文重新直译敌人名。
- 孢裂泰坦、喷气旅巨型炙炎者：未找到独立的完整名称条目，按游戏已有的本体名与变种或阵营名组合。
- 招式名称：Wiki 提供的英文名称没有出现在读到的游戏字符串表中。其他语言使用本模组校订译文，不标称官方译名；不把描述性动作短语替代英文专名。
- 说明文字：核对限定动作、取消条件和 0–0.50 秒延迟参数，改写生硬句子。各语言的菜单只显示本语言文本。
- 此次没有经过外部母语译者人工审校；名称的可核对来源与本模组译文已分别标明。
