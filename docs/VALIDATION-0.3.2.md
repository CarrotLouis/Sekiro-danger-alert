- F8 相对采集开始为 10.816、42.875、55.024、60.260、80.090 秒，分别位于原文件第 147、665、869、966、1315 行。它们只是延迟人工标记，不能当作攻击起点。
- 旧版自动检测器与采集器各自保留最早找到的 16 个存活 Crusher，远处敌人不释放名额，也不会让近处新敌人替换。

因此本轮修复观察对象选择与诊断缺口，**没有宣称已补全所有漏报招式，也没有扩大未知攻击白名单**。13 个非脚部攻击和三个跺脚排除保持原样。新版日志可进一步区分 `trigger`、`outside_10m`、`stomp`、`unmapped`、`late_sample`、`already_observed`、`cooldown`。

## 修正与采集

观察器在固定预算内轮转新候选并按当前距离选取已检查的近处对象。最多保留 16 只 Crusher；每步检查已选对象及最多 16 个新候选，发现扫描每 0.15 秒推进最多 128 个条目，待处理队列最多 4096。存活远处对象不再永久占据名额。新敌人的首次发现仍存在扫描延迟；敌人特别多时不会保证覆盖所有起点。

自动检测开启时，Crusher 采集直接写入检测器每次成功观察的对象、同时刻距离、能力和判断原因。动画独立分批，每个采集样本最多读 4 只，避免所有对象每次都读全部动画层。自动检测关闭或暂不可用时才单独采集，并标记 `capture_only`。F8 保存最近观察的年龄，不伪装成按键瞬间快照。

新炮塔采集为手动开启、只读、版本限定；不改变机器人预警逻辑。原生布局、资源候选、采集步骤与实测要求见 [敌方索敌研究](ENEMY-TARGETING.md)。20 处新增指令校验在炮塔采集时执行，不影响未使用该功能的旧检测路径。
