# Sekiro danger alert — 动画预览 R2（待确认）

本轮根据用户对原视频的五项逐帧反馈继续调整，取代 R1 的预览方案。仅生成预览，不替换游戏资源，不封包，游戏版本仍为 0.3.0。帧号从 0 开始，50 帧、60000/1001 fps，总时长约 0.834 秒。

## 调整

1. 主体起始为最亮的粉白色，随后逐步转为红色、暗红色。颜色、发光强度与透明度分别控制，避免全程保持相同色相、只改变整字透明度。
2. 增强近处和远处的连续光晕，增加宽阔的红色外围辉光。光晕有自己的强度和半径变化，随大字层展开而增强，再逐渐收退；外围用平滑圆形衰减收尾，避免方形边界。
3. 主体从 0.70 倍减速放大到 1 倍，第 34 帧停止。指数减速曲线在前 19 帧完成约九成增量，之后仍持续微量放大，避免 R1 中第 14 帧骤停。
4. 大字层独立放大至 1.85 倍，第 19 帧停止；从第 11 帧起淡出，第 24 帧完全消失。因此第 11–19 帧同时放大和淡出。
5. 在颜色变暗、非线性整体淡出的基础上，加入由笔画内部厚度及平滑杂色场控制的空间侵蚀。薄笔画、笔画边缘更早消退，不同区域的消退时间不同；光晕同步响应仍然发光的笔画。

仍使用用户提供的「極太行書」字体。它是独立程序化近似，不是原视频像素级复刻，也没有使用 AE 插件。

```powershell
python tests/test_preview_effect.py

```

输出在 `outputs/Sekiro danger alert Animation R2/`，不会上传：

- `PNG/`：50 张带透明通道的 PNG。
- `Sekiro danger alert R2 59.94fps.mp4`：单次动画，准确帧率。
- `Sekiro danger alert R2 Preview.mp4`：播放三次，每次后留约一秒空白。
- `Sekiro danger alert R2 Preview.gif`：循环图，每轮额外一秒空白；GIF 的颜色及帧间隔有限，请优先以 MP4 判断渐变和速度。
- `Sekiro danger alert R2 Comparison.mp4`：左原素材、右 R2，同帧同步播放。
- `Sekiro danger alert R2 Compare Early.png`：第 0、6、11、19 帧，每组左原版、右 R2。
- `Sekiro danger alert R2 Compare Late.png`：第 25、33、41、46 帧，同样左右排列。
- `preview.json`：曲线、帧率、字体与视频指纹、参考视频固定裁切位置。

比较时，原视频固定裁切 `(x=640, y=250, width=540, height=540)`，统一缩放到 768²，与预览大致对齐。所有帧使用同一裁切与比例，没有逐帧缩放、移动、改速或错帧。不同来源的字形和杂色细节不要求逐像素对应。

## 检查与限制

离线测试验证：主体放大持续到第 34 帧且逐步减速；大字放大/淡出时间重叠；独立白到红的变色；边缘及不同噪声区域的侵蚀先后；连续 alpha 和透明边界；动态光晕曲线；50 帧时长与最后一帧透明。另运行原游戏素材检查，确认生产素材未改变。

检查同帧画面后，已修正初次 R2 尝试中的大字过度发红、中段亮部过曝和外围方形光晕边界。预览中的杂色位置及消退细节仍是近似；是否达到用户期待需要视觉确认。尚未验证游戏材质压缩、游戏内缩放或混合效果。
