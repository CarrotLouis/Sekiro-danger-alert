Sekiro danger alert 0.8.3 — 定向采集版 / Diagnostics

安装
本包沿用 0.8.2 的完整警报规则和时机，只扩展定向采集。
它不是蟑龙误报或移动工厂“确认开炮前”预警的修复包；不会改为开炮后提示。
单独的 Diagnostics 设置页仍为六项，没有增加普通设置。
与普通包使用同一 GUID 和入口，只启用其中一个，不要同时部署。
原有位置、大小、音量和招式开关保存值继续保留。
依赖 Bingus Shared Loader v18+、Mod Options Menu v1.2 / API 3。

客机测试分工
房主和客机均安装 Enemy Spawner 0.3.1，客机可自行选择敌人并 APPLY 请求房主生成。
你当客机：在自己的电脑安装本采集版，让敌人实际攻击你并由你记录。
单纯生成时，朋友无需安装警报本体。
本轮蟑龙目标分歧需要同场两端各自的日志，建议两人都临时装本采集版；不能以主机一份代替客机。
客机请求的敌人生成在客机前方，初始目标指向客机；若房主直接生成，初始目标仍为房主。
双方必须装新版 0.3.1 生成工具，联机服务传递请求会有等待时间；不要连续重复 APPLY。
0.3.0 有读取地址类型错误，会在启动联机通道时关闭；本次必须双方更新并完整重启。
猎杀器单人采集已核对，可先在单人任务调整两种延迟并测试飞扑时机。

操作
1. 完整重启游戏，等待至少 20 秒，进入地面任务。
2. 打开 Sekiro danger alert · 采集 / Diagnostics。
3. 选择采集阵营，再在该阵营的招式选项中选择目标，其他两个阵营的选择不参与此次采集。
4. “采集场景”选攻击本人；“开始或停止采集”选开始，APPLY 后关闭菜单。
5. 先确认开始/停止采集行的说明显示“正在采集”且有效样本数在增长，再关闭菜单测试。
   每次看见所选敌人开始出招时按 F8，不必等命中。说明区的 F8 次数应增长。
   连按可能对应多个敌人，保留各次时间；不是一条 F8 就强行认作一次独立攻击。
6. 采完选择停止并 APPLY；否则两分钟自动停止。再次开始会先结束旧文件，再建立新文件。
7. 攻击队友的对照应另开一份，采集场景选 Comparison；仍由客机本人记录。

本轮只补两种
1. 蟑龙：两人同场，各自在自己的 Diagnostics 选虫族 → 蟑龙俯冲吐息，开始采集。
   尽量只留一只蟑龙，让它交替对两人俯冲，约 3～5 次；悬浮吐息不算。
   各自在看到危或看到俯冲时按 F8，照实保留误报 / 未报，不能只保存房主文件。
   完成后把朋友的对应 JSONL 复制到你本机 Logs/Teammate/ 子目录，与你的文件分开放。
   网络实体 ID、能力及 UTC 起始时间用于对应两端；进程单调时钟不能直接跨电脑相减。
2. 移动工厂：可单人，选机器人 → 移动工厂炮击，记录约 30～60 秒。
   尽量只留一只，保留真正开炮和只闪灯没开炮的几轮。
   每轮闪灯时按一次 F8；若随后开炮，在第一发真正出膛时再按一次，后两发不用连按。
   F8 只是视觉标记，人的按键延迟会保留，不把它当精确发射时刻。
   两种招式分文件采；其他敌人暂不需要重采。

范围
这是只读采集，不修改游戏内存、不调用攻击或网络接口。
采集页显示停止原因、有效观察帧和 F8 次数；有效帧不等于已确认的攻击次数。
可选 aim 读取失败保留其他通道和 F8，不丢掉整份记录；场景/潜兵/Health 等必须通道仍有停止门禁。
记录当前潜兵、敌人所有权、活动及非活动能力、同步目标、Behavior 网络状态、原生 AI / 武器状态和 F8 时间。
蟑龙增加 flying 网络行；移动工厂增加 ProjectileWeapon 实例计时 / 状态字节；两者增加完整 Behavior 网络行。
这些新增字段只供研究，不把未知整数当成锁定目标，不把武器计时当成确认开炮。
两种定向采集标称 20Hz，其他招式 10Hz；高耗时降至 5Hz，超出 20ms 停止。
原生 AI 在客机上只作为缓存诊断，不能当作权威目标。
警报仍按招式 / 锁定判断，无距离限制；诊断仅观察指定招式的最多 8 个近邻对象，范围 2000m。
采集有读取、耗时、120 秒和 8 MiB 上限，离开任务 / 增援 / 读错等会停止或报告原因。
恢复全部默认值会同时停止采集、重置诊断选择。平时使用普通包即可。
