Sekiro danger alert 1.1.0-dev.1 — 新增招式采集版

本包用于把新招式的实际画面、Ability 状态、索敌与发射输入对应起来。
当前自动预警仍为 1.0.0 的原有招式与时机；新增招式尚未接入自动预警。
新开关、三组合并与冲锋距离设置将在状态确认后的功能包中启用；不要把采集选项当作预警开关。
与普通版共用 GUID、入口和原设置值，管理器中只启用其中一个。采完可恢复普通 1.0.0。
依赖 Bingus Shared Loader v18+ 和 Mod Options Menu v1.2（API 3）。

安装与开始
1. 导入本 ZIP，替换普通警报包；完整重启游戏，等待至少 20 秒。
2. 单人可先测。联机时在被攻击的那台电脑采本人；放怪工具联机双方都需启用 0.4.0。
3. MODS → Sekiro danger alert · 采集 / Diagnostics：选采集分组，再选该组招式。
4. 场景选“攻击本人”，操作选“开始采集”，APPLY 后关闭菜单，等待约 5–10 秒完成目标发现，再诱导攻击。
5. 按下述时机按 F8；允许反应延迟，无需追求精确到帧。一段尽量记录同类动作 5–8 次。
6. 选“停止采集”并 APPLY；也会在两分钟、离开任务、本人变化或超预算时自动停止。
7. 开始前未停旧段也可再次开始，旧文件会先正常收尾，不会覆盖原记录。

分组与内容
“虫族新增”：
- 抚育喷涌虫（Nursing Spewer）持续吐酸：抬头/张嘴准备吐酸时按 F8，不要标普通近战。
- 胆汁喷涌虫（Bile Spewer）持续吐酸：同上，不要标远距离抛射。
- 钻地喷涌虫（Rupture Spewer）持续吐酸：同上，不要标钻地、破土或抛射。
- 霸王虫·出土后下压：身体向前扑压准备拍地时按 F8。
- 霸王虫·破土拍击：破土后马上拍击的这类动作，出现时按 F8。
- 霸王虫·三轮扫射吐酸：这一轮吐酸开始前按一次 F8，不必每条酸液都按。
- 霸王虫·直线吐酸：长直线吐酸变体开始前按一次 F8。
- 四类强袭虫·冲锋：依次测普通、孢子、巨兽、钻地四种，每种单独一段。开始真正奔跑冲锋时按 F8。
  让它从 10m 外朝本人冲来；尽量包含贴身启动、飞扑躲过后重新靠近、停住后再次冲锋。
  普通转身、走路、跺脚不要标。无需估算 5m 或在进入距离时按键，日志会记录距离变化。
- 虫族指挥官·冲锋：普通、阿尔法各一段；真正冲锋开始时按 F8，和走路/近战分开。

“光能及友军”：
- 光能小炮台（Gazer）激光：看到眼部开始蓄力/聚光时按 F8，保留完整开火与收束。
- 光能大激光塔（Gazer Spire）激光：同上。
- 光能电塔（Lightning Spire）电击：看见蓄电、即将放电时按 F8；若看不见前摇，放电时按也可以，请说明。
- 友军特斯拉塔（A/ARC-3）电击：用支援配备召唤，分两段记录：
  A. 场景选“攻击本人”，靠近到实际会电到本人；每次明显蓄电/放电时按 F8。
  B. 场景选“攻击队友等对照”，让它攻击附近敌人，同时本人站在可能被连锁电到的位置，电弧发生时按 F8。
  请说明哪些放电确实打中了本人、哪些只电敌人；不能单凭“塔正在开火”认为它锁定本人。

对照
对每类有锁定行为的单位，尽量补一小段攻击队友或中途取消的对照，场景选“攻击队友等对照”。
取消蓄力、不发射、普通移动等误按无需删日志，告诉我大概第几次即可。
霸王虫两个下压变体最终共用一个开关，两个吐酸变体也共用一个开关；这里只为分辨记录而拆开。
三类喷涌虫未来均默认关闭，其余本次新增项默认开启。

放怪工具
使用独立 Sekiro danger alert - Enemy Spawner 0.4.1。
“使用列表”选新增，再在“新增敌人”选三类喷涌虫、霸王虫或两类指挥官；原有四种强袭虫仍在原有列表。
0.4.1 在新增列表最后追加 Gazer 小炮台核心、Gazer Spire 激光塔核心，仅支持单人光能任务，尚需实机验证；不生成完整塔基或任务场地。
先确认核心的外观、转向、开火正常，再分别选择本采集包的 Gazer / Gazer Spire 范围记录。光能电塔仍需在相应任务寻找。
霸王虫要求 7–10 难度、无现存实例，每任务本工具最多一只。实际生成、AI 与地形仍需实机确认。

交回文件
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\
Sekiro danger alert-Combat-<所选招式>-requested-<时间>-<序号>.jsonl
对照文件中 requested 会是 comparison。
同时保留 Sekiro danger alert.log；若放怪失败，再附双方的 Sekiro danger alert - Enemy Spawner.log。
需要的是上述 JSONL 的完整文件，不是仅有启动状态的普通日志；不必提供游戏二进制文件。

安全与性能范围
读取沿用现有版本指纹、对象身份、Health/Ability/AI/Aiming/WeaponInput 校验，失败只记录不可用。
启动和菜单注册不采样，只有手动开始后才启用 F8；每段最多两分钟、8 MiB，原始记录不写进发行包。
本包没有新内存写入和新原生调用，也没有把新单位名猜成攻击事件。
离线检查不能证明实际前摇与时间窗；补齐数据后才生成新功能包。
最终冲锋范围改为强袭虫、指挥官两个独立滑块，各 0–15m、1m 步进、默认 5m；本采集包暂未注册这两个预警设置。
