# Sekiro danger alert - Enemy Spawner 0.4.1

用于警报实测的独立 Bingus Lua addon，支持 22 类移动敌人，另有两种待验证的 Gazer 武器核心。原有 22 项索引、GUID 和入口保持稳定，新增小炮台和大激光塔核心为 23、24 项。与警报本体分别启用。

设置共四行：“使用列表”选择原有或新增，再在对应的敌人列表选择，最后应用“生成一只”。每份列表最多 16 项，选择本身不触发生成。沿用 `SDAES2` 协议及原有独占成员属性；联机双方均使用 0.4.1。原有 22 项继续支持客机请求。

霸王虫要求 **7–10 难度**，已有同类实例时拒绝创建，每任务本工具最多生成一只。友军特斯拉塔使用支援配备召唤，光能电塔暂未加入。

**Gazer 小炮台和 Gazer Spire 激光塔核心仅支持单人光能任务，尚需实机验证。** 生成的是带有 Behavior、炮座、传感器和激光武器组件的实体，不生成完整塔基、任务场地或传送门。它们没有 `EnemyPackageComponentData`；通过本机原生场景资源包的内容索引确认依赖，运行时复核三种组件定义、资源与模型就绪后，复用原有通用创建请求。未新增原生调用。两种核心在多人、客机请求和未知玩家状态下一律拒绝，并在实际创建前重新检查；建筑的联机资源加载仍未验证。

在空旷平地各生成一只，先确认外观、转向和开火，再用现有 1.1.0-dev.1 Diagnostics 选择相应范围采集。可以验证核心是否无需对应任务也能工作，不能凭离线索引宣称实机已成功。

房主可在自己菜单直接生成。客机也可选择敌人并 APPLY，**双方都必须装并启用本版**：客机发起请求，由房主准备资源并创建在请求者前方约 20m，初始目标也是请求者。只装客机一端不能让未装工具的房主响应。双方在地面任务且潜兵存活，阵营匹配；粉碎者、猎杀器在光能族任务测试。首次等待资源，之后有 3 秒倒计时。镜头朝向在请求时取值，位置在实际生成时更新；请选平地，未进行地形射线校准。

通信使用游戏已接入的 PlayFab lobby member data，独占 `sda_spawn` 键。沿用 HD2Runtime 已核对的 ABI / 布局，并与本机保留代码复核；没有聊天消息、任意 RPC、内存写入或客机本地权威创建。无需安装 HD2Runtime。首次发现 lobby 后等 10–20 秒，属性异步传递还可能等数秒；发布间隔至少 5 秒。客机等待结果最长 180 秒，忙碌 / 失败后可重试，避免连续 APPLY。

房主根据 SDK 中的发送 peer，绑定当前玩家列表、网络 avatar、Health / Unit 和位置；请求不携带坐标、资源哈希、代码或地址。重放 / 过期请求不生成。任务 / 房主 / 请求者死亡或增援会取消；所有客机共享房主侧每任务 32 次、至少 3 秒间隔和容量 / 资源门禁。穿刺虫仍需 **5–10 难度**，并检查当前触手正权重、表身份和独立模型；保留此前低难度闪退修复。

每个客户端的日志和状态在 `%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/Sekiro danger alert - Enemy Spawner.log` 与同名前缀 `-STATUS.txt`。客机不出怪时同时保留房主和客机日志。双方启用此测试工具后，会响应同房间内有效的白名单生成请求；平时可禁用独立工具。

离线检查覆盖真实游戏 LuaJIT、真实 ModOptionsMenu、封包、native ABI、资源等待与召唤检查、双端请求 / ACK、一次性、当前房主 / 请求者绑定、超时、换任务 / 死亡取消、消息边界、发布限流和故障隔离。两种核心的原生组件复核、单人限制及拒绝时零次原生调用均有检查。用户已返回九类移动敌人的采集数据；这不代替新炮台核心验证。详见[本次扩展记录](../../docs/EXPANSION-1.1-PREPARATION.md)及 [0.8.2 验证记录](../../docs/VALIDATION-0.8.2.md)。

构建：

```powershell
$env:HD2_LUA51_DLL = '你的游戏目录/bin/lua51.dll'
python tools/enemy_spawner/build.py --mom-source work/ModOptionsMenu
```

未自动部署或发布 Release，ZIP 只写入忽略的 `outputs/`。完整随包说明来自 [入口内嵌指南](src/entry.lua)。
